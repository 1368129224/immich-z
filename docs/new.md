# iOS 照片页与查看器交互及手势细化规范 (Photos & Viewer Spec)

> **文档定位**：本规范为 `ios-feature-development-plan.md` 中“第 3 节 照片页面”与“第 4 节 照片查看器与详情页”的工程级细化替代方案。
> **核心目标**：在严格遵守“跨页面数据与安全合同（第 2 节）”的基础上，在界面布局、手势冲突仲裁、转场物理动画及微交互反馈上 1:1 对齐 iOS 原生《照片》App。

---

## 1. 底层视图架构与手势仲裁基座

为实现 10 万级图库下的 120Hz 丝滑滚动、底部最新定位、捏合连续缩放以及跟手共享元素转场（Hero Transition），底层实现须遵循以下技术约束：

1. **网格容器选型**：
   - 时间线网格底层须采用 `UICollectionView`（通过 `UIViewRepresentable` 桥接至 SwiftUI），配合 `UICollectionViewCompositionalLayout`（或自定义高性能 Layout）实现，避免使用纯 SwiftUI `LazyVGrid` 处理超大图库倒序定位与连续手势布局插值。
2. **共享元素锚点管理（Transition Target Tracking）**：
   - 网格需暴露根据资产唯一身份（`NativeGridItem.id`）查询当前屏幕坐标系 `CGRect`、动态滚动至可见区域（`scrollToItem`）、以及单独隐藏/恢复指定 Cell 视图（`cell.isHidden`）的同步接口，用于查看器下滑返回时的无缝落位，严禁出现双图重影。
3. **全局手势优先级原则**：
   - 所有自定义 `UIGestureRecognizer` 必须通过 `UIGestureRecognizerDelegate` 显式声明互斥（`require(toFail:)`）与并发（`shouldRecognizeSimultaneouslyWith`）策略，严禁依赖系统默认偶发顺序。

## 2. 照片页面（Timeline Grid）：信息架构与视图控制

### 2.1 来源筛选与顶栏控制
- **来源切换**：支持 **全部／本机／云端** 三态切换。双端已匹配资产在“本机”和“云端”筛选下均出现，在“全部”下严格合并去重仅出现一次。拒绝 PhotoKit 权限时仍可正常浏览“云端”。
- **切换位置锚定**：切换来源筛选时，优先保持当前屏幕中心可见的同一逻辑资产位置不变；若该资产在新筛选下不存在，则自动锚定至最临近拍摄日期的资产并给出轻量提示。

### 2.2 正方形网格 vs 原始比例网格切换（Aspect Ratio Toggle）
- **入口**：在照片页顶栏菜单（或快捷切换按钮）提供 **“正方形照片网格（Square Grid）”** 与 **“原始比例网格（Aspect Ratio Grid）”** 一键切换，复刻 iOS 原生右上角菜单体验。
- **表现**：
  - **正方形模式（默认）**：缩略图采用 `aspectFill` 居中裁切铺满正方形网格，边到边紧密排列。
  - **原始比例模式**：缩略图采用 `aspectFit` 按原图真实宽高比展示，保留视觉留白，长图与宽幅全景图一目了然。
  - **切换动画**：切换时保持当前视口中心资产锚点不丢失，通过 Layout 动画平滑过渡缩略图裁切框。

### 2.3 时间线粒度与底部悬浮毛玻璃胶囊（年 / 月 / 日 / 所有照片）
- **排列方向**：严格按拍摄日期升序排列，**最新拍摄的照片位于列表最底部**，首次冷启动进入页面直接无动画定位于最底部最新照片。
- **悬浮分级胶囊**：在非多选状态下，屏幕底部（Tab Bar 上方）常驻 iOS 原生风格的液态毛玻璃悬浮胶囊：**`年` / `月` / `日` / `所有照片`**（滚动时半透明收起或保持轻量悬浮）：
  - **所有照片**：首期基准与默认模式，连续边到边网格，按拍摄日期分组展示悬浮吸顶日期头。
  - **年 / 月 / 日视图（支持分阶段演进）**：主计划首期聚焦连续网格，本视图作为后续体验演进预留；后续可实现按“年/月/日”时间轴聚合卡片或时间段锚点跳转，点击某一年/月时以焦点放大动画直接定位至“所有照片”或“日”视图中对应的日期位置。

### 2.4 增量刷新保位与“一键回到底部（最新）”
- **禁止无条件跳底**：手动下拉/触发刷新、App 从后台回前台、分页加载、云端匹配状态更新时，必须采用**增量 Diff 更新并锁死当前可见资产与相对偏移量**，严禁重置列表或无条件滚回底部。当底部有新照片产生时，以底部非侵入胶囊提示“有新照片”，仅在用户主动点击时滚回底部。
- **快速返回最新照片**：由于时间线最新在底部，当用户向上翻阅历史照片超过 2 屏后：
  1. **单击/双击底部当前已激活的“照片”Tab 图标**，立即平滑滚动回最底部最新一张照片；
  2. 右下角浮现轻量“↓ 最新”快捷胶囊按钮，点击直达最底部。

## 3. 照片页手势状态机与多选交互（核心修正）

### 3.1 常态模式 vs 选择模式的手势严格隔离
网格严格划分为 **常态浏览模式（Normal Mode）** 与 **多选编辑模式（Selection Mode）**。右上角常驻 **“选择”** 按钮，两种模式下的手势行为完全隔离，严禁混用：

| 手势动作 | 常态浏览模式（未点“选择”） | 多选编辑模式（已点“选择”） |
| :--- | :--- | :--- |
| **单击照片** | 触发 Hero Zoom 放大转场进入查看器 | 切换该照片的选中 / 未选中状态 |
| **长按照片** | **触发原生 Haptic Touch 浮起预览 + 上下文菜单（`UIContextMenuInteraction`）** | 不触发预览菜单；允许直接作为拖拽连选起点 |
| **单指纵向滑动** | 正常上下滚动时间线网格 | 正常上下滚动时间线网格 |
| **单指横向起手滑动** | 忽略（或交由外层容器处理） | **锁定进入“涂抹式滑动连选（Drag-to-Select）”** |
| **双指捏合** | 连续焦点缩放网格列数 | 连续焦点缩放网格列数 |

### 3.2 常态长按：原生浮起预览与快捷菜单（Context Menu）
- **严禁常态长按进入多选**：修正原计划中“长按进入与拖动选取”的冲突设计。在未点击顶部“选择”按钮时，长按任意网格缩略图必须触发系统原生 `UIContextMenuInteraction`：
  1. **触觉与视觉**：伴随重按线性马达反馈，目标缩略图微放大浮起，背景网格实时高斯模糊；预览窗内若为实况照片（Live Photo）或短视频，自动静音预览播放。
  2. **快捷菜单项（依资产来源动态门控，严格遵循安全合同，不设手动上传）**：
     - `分享`（遵循第 4 节原件分享规则）
     - `收藏 / 取消收藏`（本机调 PhotoKit，双端同步更新两端）
     - `复制`（复制原图至系统剪贴板）
     - `加入相册...`（弹窗明确选择加入本机相册或服务器相册，不隐式上传）
     - `保存到本机`（当资产为“仅云端”时常显；双端已有副本时点击需提示可能重复）
     - `删除`（标红破坏性按钮，点击后弹出明确作用范围确认框：仅删本机 / 仅删云端 / 同时删除两端）

### 3.3 选择模式：横向起手滑动涂抹多选（Drag-to-Select）
当用户点击右上角“选择”进入多选模式后，启用自定义 `UIPanGestureRecognizer` 实现原生涂抹连选：
1. **起手方向锁（Direction Lock）**：
   - 手指按下移动的前 `10pt` 内计算位移分量 `dx` 与 `dy`：
   - 若 `abs(dy) >= abs(dx)`（纵向起手）：立即将该多选 Pan 手势置为 `.failed`，完全放行给 `UICollectionView` 原生滚动手势，保证多选模式下依然能顺滑上下翻找照片。
   - 若 `abs(dx) > abs(dy)`（横向起手）：**立即锁定进入“滑动涂抹连选状态”**，临时冻结 `UICollectionView` 的纵向滚动。
2. **矩形区间批量涂抹与反选**：
   - 记录起手第一张照片 `anchorIndexPath` 翻转后的目标状态 `targetSelected = !isInitiallySelected`。
   - 一旦横向锁定成功，手指后续不仅可以左右滑，还可以**直接向上/向下跨行滑动**，所有位于 `anchorIndexPath` 与当前手指所在 `currentIndexPath` 之间的连续索引照片，统一实时设置为 `targetSelected`（即起手点在未选中照片上则一路涂抹选中；起手点在已选中照片上则一路涂抹取消选中）。
   - 每新跨过一张照片触发一次轻量 `UISelectionFeedbackGenerator` 震动反馈。
3. **屏幕上下边缘自动滚屏（Edge Auto-Scroll）**：
   - 在滑动连选按住不放的状态下，若手指移入顶部或底部 `60pt` 热区，启动 `CADisplayLink` 驱动网格自动向上/向下滚动（滚动速度与手指距边缘距离成反比），同时持续将新滚入热区的照片纳入选中区间。

### 3.4 双指连续焦点缩放（Interactive Pinch-to-Zoom）
- **告别整数列跳变**：将现有的整数列跳变式捏合替换为**手势期连续尺寸插值与焦点锚定**。
- **锚点跟随**：捏合开始时记录双指中心点命中的照片 `focusAssetId` 及其在屏幕中的相对坐标；捏合过程中实时调整网格项尺寸与过渡透明度，确保 `focusAssetId` 始终紧贴双指中心不跑偏；松手时按速度与阈值平滑吸附至舒适列数档位（如 `1列 / 3列 / 5列 / 9列` 密集视图）。

### 3.5 多选操作栏与混合来源安全合同
- 支持按日期分组头一键“全选本日”及顶栏“全选/取消”。
- 底部工具栏包含：**分享、收藏、归档、加入相册、保存到本机、删除**（严格遵循母文档安全合同，不提供手动上传按钮，备份统一由后台核验与调度执行）。
- **混合来源预检**：点击任意批量操作前，先计算当前选择集内的适用数量与跳过数量/原因（例如混选了“仅本机”和“仅云端”照片时点击“归档”，需明确提示归档仅作用于已存在服务器副本的 N 张照片）；执行完毕后明确报告成功、失败与部分成功明细，绝不静默跳过或跨端误操作。

## 4. 照片查看器与详情页：手势优先级、上滑抽屉与跟手转场

### 4.1 查看器整体手势冲突仲裁矩阵（Gesture Priority Matrix）
查看器内同时存在横滑切图、双指缩放、双击缩放、下滑返回、上滑看详情、长按播放实况、单击隐藏工具栏 7 种手势，必须严格按以下状态机仲裁：

| 当前画面状态 | 手势输入 | 仲裁结果与执行动作 |
| :--- | :--- | :--- |
| **原尺寸（`zoomScale == 1.0`）且详情抽屉关闭** | 单指水平滑动（`abs(dx) > abs(dy)`） | 左右分页切换前/后一张照片 |
| **原尺寸（`zoomScale == 1.0`）且详情抽屉关闭** | **单指向上滑动（`dy < -10pt` 且纵向为主）** | **跟手向上推起底部“详情抽屉（Info Sheet）”，照片同步上移** |
| **原尺寸（`zoomScale == 1.0`）且详情抽屉关闭** | **单指向下滑动（`dy > 10pt` 且纵向为主）** | **进入“非线性跟手缩放返回（Hero Dismiss）”转场** |
| **原尺寸（`zoomScale == 1.0`）** | 单指静止长按（`> 0.15s`，位移 `< 10pt`） | 若为 Live Photo 则触发实况播放（播放期间锁定横滑与下滑） |
| **已放大状态（`zoomScale > 1.01`）** | 任意单指滑动 | **仅执行图片内部平移（Pan）**，严格禁止误触发横滑切图、上滑详情或下滑关闭；直至缩回原尺寸才恢复 |
| **详情抽屉已展开状态** | 在照片区域下滑 / 抽屉滚至顶部后继续下滑 | 跟手收起详情抽屉，照片平滑归位至屏幕中央 |
| **详情抽屉已展开状态** | 单指水平滑动照片区域 | 保持详情抽屉展开态，直接左右切换前/后一张照片并实时刷新抽屉内的元数据！ |
| **任意状态** | 单击 vs 双击 | 单击手势必须声明 `singleTap.require(toFail: doubleTap)`：双击立即以点击点为中心在 `1.0x` 与 `2.5x/铺满` 间缩放；单击切换沉浸模式（隐藏/显示顶底工具栏与缩略图条） |

### 4.2 非线性跟手下滑返回与 Hero 共享元素转场（Interactive Dismiss）
从查看器下滑返回网格不能使用生硬的系统默认弹窗下滑，必须实现与 iOS 原生完全一致的**自由拖拽缩放飞回动画**：
1. **触发与二维跟手**：
   - 在原尺寸且详情未打开时，单指向下滑动触发交互式转场。一旦触发，解除纯垂直方向限制，**照片中心跟随手指在 X/Y 二维平面自由移动**。
2. **非线性阻尼缩放与背景显露**：
   - 随着手指下移距离 `verticalDelta` 增大，照片按非线性阻尼公式缩小：`scale = max(0.45, 1.0 - (verticalDelta / screenHeight) * 0.65)`。
   - 查看器顶部导航栏、底部工具栏、缩略图滑动条在起手 `30pt` 内迅速淡出（`alpha -> 0`）。
   - 查看器黑色/深色背景遮罩透明度随下滑距离线性衰减：`backdropAlpha = max(0.0, 1.0 - (verticalDelta / 320.0))`，透出底层时间线网格。
3. **目标网格对齐与防重影（No Ghosting）**：
   - 若用户在查看器内左右翻阅了多张照片，已偏离进入时的初始照片：在转场开始瞬间，底层时间线网格静默调用 `scrollToItem(at: currentAssetIndexPath, at: .centeredVertically, animated: false)` 确保目标格子处于视口内。
   - 转场全过程中，底层网格中当前照片对应的 `GridCell` 必须保持 `isHidden = true`（留出空白槽位）。
4. **松手物理落位（Spring Snap）**：
   - 若松手时 `verticalDelta > 90pt` 或向下速度 `velocity.y > 550pt/s`：执行关闭动画。采用弹簧曲线（`response: 0.30, dampingFraction: 0.84`）将正在拖拽的照片视图的 `frame`、裁切框（从原始长宽比平滑裁切回正方形网格，若网格为正方形模式）和圆角精准动画收敛至底层网格空白槽位的屏幕坐标；动画结束瞬间将底层 `GridCell.isHidden = false` 并销毁查看器图层。
   - 若未达阈值：以同样弹簧曲线将照片弹回全屏中央，恢复背景遮罩与工具栏。

### 4.3 单指上滑呼出详情抽屉（Swipe-up Info Sheet）
- **双触发途径**：既支持点击底部工具栏的 `详情 (i)` 按钮，也支持在原尺寸照片上**直接单指向上滑动**。
- **联动视差动画**：
  - 上滑过程中，底部详情卡片从屏幕下沿跟手升起，同时上方照片容器高度/中心点平滑上移（将照片无遮挡地托举在屏幕上半区可视中心），底部缩略图条平滑淡出。
  - 达到阈值（`dy < -70pt` 或向上快速轻拂）后，以阻尼动画吸附固定在半屏抽屉档位（Medium Detent）。
- **详情页信息结构（首期与扩展）**：
  - **核心状态卡**：醒目展示本机/云端双端副本状态（仅本机、仅云端、双端已确认 SHA-1 核验通过、待核验/上传中/失败重试入口），绝不把“未知/核验失败”显示为“未上传”。
  - **基础元数据**：拍摄日期与精确时间、文件名、像素尺寸、文件格式（HEIC/JPEG/RAW/MOV）、文件体积、资产来源。
  - **相机 EXIF 卡片（次级区域）**：机身型号、镜头规格、焦距、光圈、快门、ISO 等；缺失字段如实隐藏或留空，严禁猜测。
  - **地理位置卡片**：若有 GPS 坐标，展示内嵌 `MapKit` 静态/可交互小地图及逆地理编码地点名称。

## 5. 查看器底部：高速缩略图滑动条（Filmstrip & Video Scrubber）

为补齐 iOS 原生查看器灵魂级的快速寻址体验，在底部操作栏（分享、收藏、详情、更多）正上方增设 **高速缩略图滑动条（Filmstrip Scrubber）**：

### 5.1 布局结构与当前项高亮展开态
- **位置与显隐**：位于底部工具栏上方 `8pt` 处，条高 `36pt`。当单击画面进入沉浸模式、或上滑展开详情抽屉、或处于下滑返回手势中时，随工具栏一同平滑淡出。
- **视觉形态**：
  - **非当前项**：两侧相邻照片以紧凑窄竖条缩略图呈现（宽 `16pt` × 高 `30pt`，圆角 `2pt`，间距 `2pt`）。
  - **当前居中选中项（Active Item）**：位于滑动条水平正中心，自动展开为完整正方形或原比例微缩图（宽 `32pt~44pt` × 高 `34pt`，圆角 `4pt`），且与左右两侧窄条留出 `6pt` 的呼吸间距，视觉上一眼锁定当前位置。

### 5.2 高速滑动寻址（High-Speed Scrubbing）与触觉反馈
1. **双向同步**：
   - 在上方大图区左右横滑切图时，底部缩略图条实时平滑跟手滚动。
   - 按住底部缩略图条左右拖动时，进入 **高速寻址模式（Scrubbing Mode）**，支持在 1 秒内快速掠过数百张照片。
2. **线性马达刻度感（Haptic Tick）**：
   - 在拖动缩略图条过程中，每当有一张新缩略图跨过中心焦点槽位，立即触发一次 `UISelectionFeedbackGenerator.selectionChanged()` 刻度微震（高速甩动时做最小 `30ms` 节流，保证震感清脆不粘连）。
3. **两阶段加载防卡顿（Two-Phase Media Loading）**：
   - **高速滑动期**：当缩略图条处于快速滚动中时，上方大图查看器**仅同步渲染内存/磁盘已有的低清网格缩略图**，立即取消中间途经照片的高清大图、RAW 解码、远端视频流或 Live Photo 请求。
   - **减速停靠期**：仅当手指停顿或滚动减速停靠在目标照片上超过 `120ms` 时，才发起该照片的高清原图、远端认证视频流或实况照片加载。

### 5.3 视频播放态的原位变形：帧缩略图进度条（Video Frame Scrubber）
- 当查看器切换到**视频资产**时：
  - 视频自动静音/按系统音量播放（不循环，切走立即暂停并释放解码器）。
  - 底部原本展示当前视频单张缩略图的中心槽位（或在缩略图条正上方），平滑横向展开为一条 **多帧视频进度条（Video Frame Scrubber）**，左侧附带 `播放/暂停` 按钮与当前时间戳，右侧附带 `音量/静音` 按钮。
  - 用户可直接按住视频帧进度条左右拖拽进行精确到帧的预览寻址（Seek）；对于 Immich 远端认证视频，需确保通过带认证 Header 的 `AVURLAsset` / `AVAssetResourceLoader` 支持 HTTP Range 分片拖拽播放与请求取消，并经过真机弱网验证。

## 6. Live Photo（实况照片）原生触发、双端合成与控制

### 6.1 本机与云端 Live Photo 的加载与合成机制
- **本机资产**：直接通过 PhotoKit `PHImageManager.default().requestLivePhoto` 请求原生 `PHLivePhoto` 对象并交由 `PHLivePhotoView` 渲染。
- **Immich 云端资产（双文件合成）**：
  - Immich 服务端将实况照片存储为一张静态图片资产 + 一个关联的短视频资产（通过 `livePhotoVideoId` 关联）。
  - 客户端需内置按账户隔离的 **`LivePhotoSynthesizer`（实况合成缓存器）**：当浏览云端实况照片时，后台并发拉取高清静态图与对应的 `livePhotoVideoId` 视频流，在本地临时缓存目录中写入匹配的 `AssetIdentifier` 元数据并通过 `PHLivePhoto.request(withResourceFileURLs:...)` 合成为原生 `PHLivePhoto` 实例，再喂给 `PHLivePhotoView`。
  - 合成结果按 `账户ID + 服务器AssetID` 缓存于本地临时媒体缓存区（清理缓存时可安全清除，不影响指纹与备份队列）。

### 6.2 查看器内的原生手势触发与防冲突
- **原生组件渲染**：查看器展示实况照片时，底层使用系统原生 `PHLivePhotoView`，完整保留苹果原生的**长按微震动、画面边缘微放大呼吸感以及音画渐入渐出效果**。
- **手势冲突优先级**：
  - 挂载 `livePhotoView.playbackGestureRecognizer`。
  - 当单指按下静止超过 `0.15s` 且移动距离 `< 10pt` 时，触发实况播放；一旦实况开始播放，暂时冻结外层 `UIPageViewController` 的左右切图手势与上下滑动手势，直到手指抬起停止播放。
  - 若手指按下后在 `0.15s` 内发生明显水平位移（`> 10pt`）或第二根手指按下（双指捏合），立即中断实况触发，优先响应横滑切图或双指缩放。

### 6.3 左上角“实况（LIVE）”原生胶囊与交互菜单
- **视觉位置**：当当前照片为实况照片（本机或云端存在关联视频）时，在查看器左上方（顶部导航栏下方安全区）展示原生毛玻璃胶囊：**`◎ 实况`**。
  - 若云端实况视频部分正在后台下载合成中，胶囊内同心圆图标显示轻量旋转加载态；合成完毕后恢复常驻图标。
- **点击胶囊下拉菜单**：点击左上角 `◎ 实况` 胶囊，弹出原生 `UIMenu`：
  1. **实况开启 / 关闭（Live On / Off）**：允许用户临时或持久将其作为静态照片查看。
  2. **声音开启 / 静音（Mute Toggle）**：允许单独开关该实况照片长按时的环境音。

## 7. 收藏、原件分享、删除与错误处理（安全合同落地）

1. **双端收藏一致性**：
   - 本机独有照片通过 PhotoKit 修改收藏状态；云端独有照片调用 Immich API 修改；**双端已匹配资产点击收藏时，同步更新本机 PhotoKit 与服务器两端**，若其中一端失败（如离线或 PhotoKit 权限受限），必须如实展示分项成功/失败提示，严禁误报“全部成功”，且结果实时同步回照片页网格角标。
2. **真实原件分享与隐私确认**：
   - 点击分享优先准备真实原始文件（包含原始 EXIF、Live Photo 配套视频或原画质视频），准备期间显示进度条与“取消”按钮。
   - **严禁将需要认证 Header 的服务器直链 URL 直接丢给系统分享面板**，必须下载落地为本地可读临时文件后再拉起 `UIActivityViewController`。
   - 若因离线或 iCloud 原件未就绪无法获取原件，必须弹窗询问用户“是否改为分享当前清晰度预览图”，严禁静默降级画质分享。
3. **删除范围强确认**：
   - 查看器与多选删除共用同一安全服务：每次点击删除必须明确展示作用范围（`仅从此设备删除` / `仅从 Immich 云端删除` / `从设备与云端同时删除`），对双端照片不设危险默认勾选。
   - 若自动备份已开启且该照片仍在勾选的备份相册中，选择“仅从云端删除”前必须弹窗告知“后续自动备份可能会将其重新上传”，删除成功后立即使旧服务器关联缓存失效。
4. **原位错误分类与重试**：
   - 原图、Live Photo 或视频加载失败时，必须在查看器原位区分展示：**当前离线、PhotoKit 权限不足、iCloud 原件下载失败、服务器错误、格式不支持**，并提供一键“重试”按钮。

## 8. 照片页与查看器真机验收清单（DoD）

在进入下一批次前，照片页与查看器必须在真机上通过以下专项验收：

- [ ] **手势不打架验收**：常态下长按照片 100% 弹出浮起预览菜单（不进多选）；点击“选择”后，纵向滑动能顺滑滚屏，横向起手滑动能丝滑涂抹连选且滚到顶/底边缘会自动滚屏。
- [ ] **转场无重影验收**：在查看器内左右横滑翻阅 20 张照片后，向右下角斜向拖拽松手，照片能沿抛物线精准缩回底层网格对应的新格子中，过程中原格子空白无重影，松手瞬间严丝合缝。
- [ ] **上滑抽屉与横滑联动验收**：查看器内单指上滑能丝滑推起详情抽屉；保持抽屉打开状态下左右滑动上方照片，抽屉内的文件名、EXIF、双端核验状态与小地图能实时无闪烁刷新。
- [ ] **底部缩略图条高速寻址验收**：按住底部 Filmstrip 快速横扫 500 张照片，线性马达震感清脆、大图区实时切换低清预览不卡死主线程，松手停顿后 200ms 内自动补齐高清大图；切到视频时自动变形为帧进度条且支持拖拽 Seek。
- [ ] **实况照片双端体验验收**：本机与 Immich 云端 Live Photo 均能通过长按画面流畅播放并带原生呼吸震动；左上角 `◎ 实况` 胶囊可正常开关静音；长按播放时不会误触左右切图。
- [ ] **位置与安全不回退验收**：切换“全部/本机/云端”或切换“正方形/原始比例”、以及后台回前台时，列表不跳回底部，当前可见资产保持稳定；点击底部“照片”Tab 能一键顺滑回到最底部最新照片。
